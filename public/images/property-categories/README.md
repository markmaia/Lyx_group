# Explore Our Properties images

Replace a category image by overwriting the matching file. Use these exact names:

- `residential.jpeg`
- `commercial.jpeg`
- `off-plan.jpeg`
- `land-plots.jpeg`
- `rentals.jpeg`
- `holiday-homes.jpeg`

Landscape photos work best. The category cards load these from this folder and keep their illustrated fallback if an image is missing.
